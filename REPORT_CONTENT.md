# CS3301 – Full Stack Development CIE-2
## Project: SpendWise – Expense Tracker

### Problem Statement
Tracking daily expenses manually makes it difficult to search transactions, group spending by category and understand total expenditure.

### Objective
Develop a React.js expense tracker that demonstrates reusable components, props, state, effects, event handling, forms and client-side routing.

### Technologies
React.js, JavaScript, Vite, React Router, HTML, CSS and LocalStorage.

### Components
App → Navbar, Dashboard, Expenses, AddExpense, About, NotFound; Dashboard uses StatCard and Expenses uses ExpenseRow.

### React Concepts
- Functional components: all major pages and reusable UI.
- Class component: About.jsx.
- Parent-child: App passes expenses and callbacks to pages/components.
- Props: StatCard and ExpenseRow receive data through props.
- useState: search, filter and form state.
- useEffect: saves expenses to LocalStorage.
- Event handling: click/change/submit.
- Form handling: Add Expense form.
- Routing: Dashboard, Expenses, Add Expense, About and 404.
- Responsive UI: CSS media queries.

### Modifications
1. Category filtering.
2. Search functionality.
3. Total and average spending dashboard.
4. LocalStorage persistence.
5. Responsive layout.
